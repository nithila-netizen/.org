# Your photos go here

Drop your image files into this folder using the **exact filenames** below, then
`git add . && git commit -m "add photos" && git push`. They'll appear on the site
automatically (each spot shows a placeholder until its file exists).

JPG or PNG both work — just keep the filename (including `.jpg`) exactly as listed.

## Filenames the site is looking for

| Filename                          | Which photo |
|-----------------------------------|-------------|
| `grad-creekside.jpg`              | You in red — Creekside High School graduation / Benacquisto Scholarship |
| `museum-future-dubai.jpg`         | White dress — Museum of the Future, Dubai (origin story) |
| `basketball-2025.jpg`             | You + college roommate in Florida shirts (2025 championship fun fact) |
| `nature-road.jpg`                 | Arms out on the forest road (Canada) |
| `nature-hike.jpg`                 | Hiking selfie with your little sister |
| `onehealth-team.jpg`              | Group in suits doing the gator chomp (One Health case competition) |
| `uf-teach-stem.jpg`               | Group in blue — UF Teach STEM camp |
| `girls-on-the-run.jpg`            | Girls on the Run group |
| `nirmaa.jpg`                      | A screenshot of nirmaa.com |
| `onset-1.jpg`, `onset-2.jpg`, `onset-3.jpg`             | ONSET Instagram posts (carousel) |
| `pawsthetics-1.jpg` … `pawsthetics-3.jpg`               | UF Pawsthetics Instagram posts (carousel) |
| `180dc-1.jpg` … `180dc-3.jpg`                           | 180 Degrees Consulting Instagram posts (carousel) |

Want more than 3 posts in a carousel? Add `onset-4.jpg`, etc., and add the same
filename to the `posts` list in `data.js`.
